FLIPKART SALES ANALYSIS USING SQL
Project Overview
This project analyzes e-commerce sales data using MySQL 8.0.46. It
focuses on sales, customers, products, and payment methods.
Note: This is a Flipkart-themed practice project. The data is not
confirmed to be actual Flipkart company data.

Dataset
The project uses three CSV files:
- sales_Flipkart.csv -- sales and order details
- products_FlipKart.csv -- product details
- customers_FlipKart.csv -- customer details
Tools Used
- MySQL 8.0.46
- SQL
Analysis Questions
1. What are the overall sales?
2. Which categories generate the most sales?
3. Which payment methods are most used?
4. Which customers spend the most?
5. Which suppliers perform best?
6. How can customers be grouped by spending?
7. Which transactions are above average?
8. Which customers spend more than average?
9. How do product categories rank by sales?
10. Who are the top customers in each category?
11. How do monthly sales change?
12. What are the customer and product performance results?
SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- JOIN
- Aggregate functions
- CASE WHEN
- Subqueries and CTEs
- Window functions
Key Results
- Total sales: 1,284,338.10
- Total transactions: 1,000
- Customers with sales: 637
- Average transaction value: 1,284.34
The dataset does not specify a currency, so sales values are shown in
dataset units.
How to Use
1. Download the three CSV files.
2. Create a database named Flipkart_Analytics in MySQL.
3. Import the CSV files into tables named sales, products, and
   customers.
4. Run the SQL queries to see the results.
Project Purpose
This project demonstrates how SQL can be used to analyze sales data and
find useful business insights.
